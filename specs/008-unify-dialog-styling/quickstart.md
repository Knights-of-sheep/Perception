# Quickstart: 弹窗样式层次化统一 — 验证指南

**Date**: 2026-08-30 | **Feature**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md)

> 本指南是**端到端验证/验收手册**（非实现文档）。实现细节见 `tasks.md` 与 `src/ui/` 源码；契约见 [contracts/dialog-style-contract.md](contracts/dialog-style-contract.md)。

## 1. 前置条件

- Windows 10/11 + VS2022 + CMake ≥ 3.16 + Ninja（`scripts/build.ps1` 一键构建）
- Qt 5.15.2 / VTK 9.4.1 / CPython 3.13 已按 README 配置

## 2. 自动校验（每轮实现后运行）

```powershell
# 1) 构建
scripts\build.ps1

# 2) 派生函数校验（SC-001 自动部分）：
#    - Dark/Light：25 套 |L(dialogBg)-L(windowBg)| ≥ 8
#    - 全部：dialogBg vs text 对比度 ≥ 4.5:1
#    - HC：dialogBg==windowBg 且 border vs windowBg ≥ 7:1
ctest --test-dir build -R theme_dialog_layer --output-on-failure

# 3) 布局计算语义校验（SC-006 自动部分，WS2）：
#    - Row=N×1 / Column=1×N / Grid=比例+优先级轴约束（FR-008~010）
#    - constraintAxis 全组合、间隙 cellSize 扣除（FR-010/015）
ctest --test-dir build -R layout_manager --output-on-failure

# 4) 回归（宪法质量门禁）
ctest --test-dir build
pytest tests\python
```

**预期**：`theme_dialog_layer` 与 `layout_manager` 全部通过；`ctest`/`pytest` 全绿。

## 3. 手动验证矩阵（SC-002 / SC-003 / SC-004 / SC-005）

### 3.1 弹窗类型 × 主题家族 矩阵

对每个主题家族抽样（至少各 1 套，建议：Dark Classic、Light Classic、HC Black），打开**全部 10 类弹窗**逐项核对：

| 弹窗 | 打开方式 | 背景层次 | 1px 边框 | 标题栏一致 | 可拖拽 | 关闭 |
|---|---|---|---|---|---|---|
| 帮助 | 菜单 Help | 与主界面可区分 | ✓ | ✓ | ✓ | ✓ |
| 关于 | 菜单 About | 同上 | ✓ | ✓ | ✓ | ✓ |
| 打开文件 | Ctrl+O | 同上 | ✓ | ✓ | ✓ | ✓ |
| 导出图片 | 菜单/工具栏 Export | 同上 | ✓ | ✓ | ✓ | ✓ |
| 导出命令 | 控制台菜单 | 同上 | ✓ | ✓ | ✓ | ✓ |
| 设置日志路径 | 日志菜单 Set Log Path | 同上 | ✓ | ✓ | ✓ | ✓ |
| 布局设置 | 子窗口菜单 Layout Settings | 同上 | ✓ | ✓ | ✓ | ✓ |
| 导出失败警告 | 导出到不可写路径 | 同上 | ✓ | ✓ | ✓ | ✓ |
| 清除日志确认 | 日志菜单 Clear Log History | 同上 | ✓ | ✓ | ✓ | ✓ |
| 清除失败警告 | 清空只读目录后清除 | 同上 | ✓ | ✓ | ✓ | ✓ |

**核对要点**：
- **背景层次（SC-001/SC-004）**：弹窗背景与主窗口背景有可感知差异；深色主题下弹窗比主界面**亮**、浅色主题下**暗**、HC 下靠白/黑边框区分；余光即可分辨边界
- **配色协调（FR-003）**：弹窗背景与主界面同色系，无孤立/刺眼色块；正文与按钮文字清晰可读
- **标题栏（SC-003）**：并排打开 ≥3 类弹窗，标题栏高度/图标/字号/关闭按钮位置一致
- **交互（SC-005）**：拖拽、关闭、按钮操作结果与改造前一致

### 3.2 主题热切换（FR-002 / SC-002）

1. 打开任意弹窗（保持打开）
2. 在「视图」菜单切换主题（跨家族：Dark → Light → HC → Dark）
3. 核对：已打开弹窗的背景/标题栏/边框**即时**跟随新主题，无残留旧色、无配色冲突

### 3.3 边界对比体验（SC-004）

邀请 5 名体验者，在深色与浅色主题下各随机打开 5 类弹窗，要求 1 秒内指出弹窗边界：
- **通过标准**：≥ 4/5 体验者全部正确指出

### 3.4 布局设置弹窗验证矩阵（SC-006 / SC-007，WS2）

**准备**：创建 ≥3 个子窗口（PyShell `create_window(...)` 或菜单），打开「视图 → 布局设置…」。

**3.4.1 三模式排布语义核对（FR-008）**：分别以 3、5 个子窗口切换三种模式，比对：

| 子窗口数 | By Row | By Column | Grid（默认行优先） |
|---|---|---|---|
| 3 | 3×1（单列，一列多行） | 1×3（单行，一行多列） | 2×2（末格留白或延伸） |
| 5 | 5×1（单列，一列多行） | 1×5（单行，一行多列） | 3×2 |

**核对要点**：Row/Column 为真正的单列/单行（非比例网格）；切换即时生效、渲染内容与视图状态保留（FR-011）。

**3.4.1b 网格填充方向核对（FR-010，2026-08-30 再修订）**：创建 **7 个子窗口**切到 Grid 并切换优先级——**行优先** → 3×3 网格按行填充（第一行 3 个、第二行 3 个、第三行 1 个）；**列优先** → 3×3 网格按列填充（第一列 3 个、第二列 3 个、第三列 1 个）；弹窗内实时预览与中央区域排布一致，方向随优先级切换即时变化。

**3.4.2 控件可用性矩阵核对（FR-009/010，2026-08-30 二次修订：约束轴 = 生效轴）**：所有控件始终可见，仅切换 enabled——逐模式核对 By Row / By Column 下优先级 + 最大行 + 最大列**禁用**（灰显，约束不参与计算）；Grid 下优先级 radio（互斥单选）+ 按生效轴启用对应 spinbox（行优先 → 启用最大列数、灰显最大行数；列优先 → 启用最大行数、灰显最大列数）。禁用控件当前值保留、切换回 Grid 后原值仍生效；可用性切换弹窗几何不跳动（SC-006）。

**3.4.3 实时预览一致性（FR-013）**：切换模式/优先级/约束/间隙时，弹窗内预览缩略示意与中央区域真实排布一致（截图并排比对）。

**3.4.4 恢复默认（FR-014）**：随意改乱配置后点击「恢复默认」→ 控件回到默认值（Grid + 行优先 + 无约束 + 不保持相同宽高 + 间隙 6），中央区域立即恢复默认排布，子窗口内容/状态不变。

**3.4.5 间隙宽度（FR-015）**：输入 0 / 6 / 50，三种模式下相邻子窗口间距随之变化；0 时无缝相邻（边框仍分隔），50 时子窗口完整可见不溢出。

**3.4.6 空态/单格（Edge Cases）**：关闭全部子窗口后打开弹窗 → 预览显示空提示；仅 1 个子窗口 → 预览显示单格铺满。
