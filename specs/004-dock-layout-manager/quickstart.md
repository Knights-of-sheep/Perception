# 快速验证指南: 子窗口布局管理

> 目标：端到端验证 spec FR-001~019 与 SC-001~012 可行。实现细节见 `tasks.md`（Phase 2）。
> 数据模型见 [data-model.md](./data-model.md)；接口契约见 [contracts/](./contracts/)。

## 前置

- 已配置依赖路径（顶层 `CMakeLists.txt` 默认：Qt5_DIR / VTK_DIR / Python3_ROOT_DIR）。
- 使用 `scripts/build.ps1`（`-Gui` 开启界面层 `PERCEPTION_BUILD_GUI=ON`）。

## 1. 构建

```powershell
powershell -File scripts/build.ps1 -Gui -Config Release
# 产物: bin/perception.exe
```

## 2. 单元测试（布局逻辑）

```powershell
powershell -File scripts/build.ps1 -UnitTests -Config Release
ctest --test-dir build -R layout_manager_test --output-on-failure
```

**预期**：`computeGrid` / `cellSize` 用例全部通过——覆盖按行/按列/网格、最大行列约束（N=1..10）、容量不足可访问、相同宽高统一尺寸、间隙一致（SC-003/004/009）。

## 3. 端到端手动验证（GUI）

运行 `bin/perception.exe`。

### 3.1 创建子窗口（双入口）

- 菜单"视图 → 新建子窗口"× 3（每次触发同一 `create_window()` 命令行，输出区回显 + 打印返回 id）；
- PyShell 执行 `create_window("曲线图")` × 1（返回 `'Plot_N'`，子窗口标题显示"曲线图"）、`create_window()` × 1（无参：标题 = id）。

**预期**：5 个子窗口出现并参与当前布局；1 秒内出现（SC-007）；两入口行为一致（SC-008）；子窗口均无系统标题栏（SC-012 抽查）；每次创建（含菜单入口）后 PyShell 输出区回显 `create_window` 命令文本并打印返回值（新建子窗口的 id，如 `'Plot_1'`），核对输出区文本 100% 匹配（FR-027 / SC-018）。

### 3.2 排列模式切换

- "视图 → 布局…"分别选择 按行 / 按列 / 网格；
- 网格模式下设置"Priority: By column"：无约束时转置排列（5 个子窗口 → 2 行 3 列）。

**预期**：立即重排、互不重叠；相邻间隙一致且 ≥4px（SC-009）；子窗口内容与视图状态不丢失（FR-013）；网格列优先转置生效（FR-006 修订）。

### 3.2.1 布局设置对话框风格（弹窗统一风格）

- 打开"视图 → 布局…"，观察对话框标题栏：应用图标 + 标题 + 关闭按钮，无系统标题栏；
- 按住标题栏拖拽移动；点击关闭按钮关闭；再打开帮助/关于弹窗对比。

**预期**：布局设置对话框与其他弹窗（帮助/关于/文件对话框）标题栏外观一致（图标+标题+关闭按钮，可拖拽），无系统原生标题栏（FR-011 / 宪法「技术栈约束 · GUI」2.0.0）。

### 3.3 最大行列约束

- 网格模式，最大列数 = 2、最大行数 = 2，5 个子窗口。

**预期**：排成 2 列、3 行；第 5 个可见可访问、不遮挡（FR-007/008/014、SC-003）；输入 0/负数/非数字时提示并回退上次有效值（FR-012）。

### 3.4 保持相同宽高

- 开启：所有子窗口宽度、高度一致（SC-004，差异 <1px）；
- 关闭：恢复开启前的独立尺寸（FR-010）；
- 开启状态下拉伸主窗口：子窗口同步等比变化（FR-009）。

### 3.5 最大化 / 全屏

- 单击选中子窗口 A → 标题区"最大化"按钮：A 占满中央区域，其余隐藏（SC-010）→ 再次点击退出，布局完整恢复；
- 标题区"全屏"按钮：A 覆盖整个主窗口工作区，属性/数据/PyShell 面板隐藏（SC-011）→ `Esc` 退出，面板与布局恢复；
- 全程 A 的渲染内容与视图状态不丢失（FR-019）。

### 3.6 稳定性与高 DPI

- 连续 50 次模式切换 / 属性修改：无崩溃、无卡顿（SC-005）；
- 系统缩放 150% / 200% 下布局不错位、控件清晰（SC-006）。
