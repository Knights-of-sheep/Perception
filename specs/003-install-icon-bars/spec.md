# Feature Specification: 安装程序图标与功能图标

**Feature Branch**: `003-install-icon-bars`

**Created**: 2026-08-25

**Status**: Draft

**Input**: User description: "将按钮icon安装到程序上，包括程序的icon和功能icon，功能icon放置在menu 和左右功能栏（纵向布局），左侧功能栏放置通用功能如 undo/redo 加载文件 加载脚本 主界面截图 主界面视频录制 refresh 数据面板控制显隐 属性面板控制显隐 命令窗口控制显隐，右侧功能栏放置各个功能按钮。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 菜单项配图标，操作一眼可辨 (Priority: P1)

用户在浏览菜单（文件、编辑、视图、帮助等）时，每个菜单项旁都有与其功能语义相符的小图标（如"打开文件"配打开图标、"撤销"配撤销图标）。用户无需阅读文字即可通过图标快速定位常用功能，菜单扫描速度显著提升。

**Why this priority**: 菜单是用户执行功能的最基础入口，图标化是本次"图标安装"的核心价值之一；且不依赖任何新功能，可与左右功能栏独立交付、独立测试。

**Independent Test**: 打开程序，逐项检查所有菜单项是否都显示语义图标；对照图标-功能映射表，抽查 10 项确认图标含义与功能一致。交付物为"菜单全部带图标"的界面截图。

**Acceptance Scenarios**:

1. **Given** 程序已启动且菜单栏可见，**When** 用户依次展开 文件 / 编辑 / 视图 / 帮助 等全部菜单，**Then** 每个菜单项均显示一个清晰可辨的图标，且图标含义与该菜单项功能一致
2. **Given** 菜单项图标已配置，**When** 用户在 150% 和 200% 缩放下查看菜单，**Then** 图标边缘清晰、无模糊或拉伸变形

---

### User Story 2 - 左侧功能栏：通用功能一键可达 (Priority: P1)

主窗口左侧有一条纵向功能栏，集中放置 9 个通用功能按钮：撤销、重做、加载文件、加载脚本、主界面截图、主界面视频录制、刷新、数据面板显隐、属性面板显隐、命令窗口显隐。每个按钮都有图标，悬停时显示功能名称提示；点击后触发与菜单对应项完全相同的行为。

**Why this priority**: 用户明确指定左侧功能栏的按钮清单，是本次交付的主体；9 个按钮中有 5 个已对应现有功能，可独立形成 MVP（先接线已有功能）。

**Independent Test**: 启动程序，在左侧功能栏逐一点击每个按钮，确认触发行为与对应菜单项一致；截图记录按钮排列与图标显示。可先交付"已存在功能的按钮全部可用"的版本。

**Acceptance Scenarios**:

1. **Given** 程序已启动，**When** 用户查看左侧功能栏，**Then** 功能栏呈纵向排列，包含撤销、重做、加载文件、加载脚本、主界面截图、主界面视频录制、刷新、数据面板显隐、属性面板显隐、命令窗口显隐共 10 个带图标按钮
2. **Given** 左侧功能栏已就绪，**When** 用户点击"加载文件"按钮，**Then** 打开文件对话框，行为与菜单"打开文件"完全一致
3. **Given** 左侧功能栏已就绪，**When** 用户点击"数据面板显隐 / 属性面板显隐 / 命令窗口显隐"三个按钮，**Then** 对应面板分别在显示与隐藏间切换，且按钮选中态（按下的状态）能反映面板当前可见性
4. **Given** 左侧功能栏已就绪，**When** 用户将鼠标悬停在任意按钮上约 0.5 秒，**Then** 出现该功能的中文名称提示
5. **Given** 功能栏按钮存在，**When** 用户点击对应功能处于不可用状态的按钮（如无文件可撤销时点击"撤销"），**Then** 按钮呈禁用态（变暗），且点击不产生任何副作用

---

### User Story 3 - 右侧功能栏：领域功能按钮 (Priority: P2)

主窗口右侧有一条纵向功能栏，放置面向数据与视图的领域功能按钮，共 9 个：放大、缩小、自适应显示、重置视图（视图操作类）与添加曲线、移除曲线、数据提取、坐标轴设置、图例（数据操作类）。用户通过右侧功能栏快速访问数据操作与视图调整功能，无需逐级展开菜单。

**Why this priority**: 右侧功能栏是用户要求的布局组成部分，但依赖按钮清单确认与部分领域功能的就绪度，优先级低于左侧通用功能栏。

**Independent Test**: 启动程序，在右侧功能栏逐一点击每个按钮，确认均触发对应功能；对尚未实现的功能按钮，确认其呈现禁用态或明确提示，不产生崩溃或静默无响应。

**Acceptance Scenarios**:

1. **Given** 程序已启动，**When** 用户查看右侧功能栏，**Then** 功能栏呈纵向排列，包含放大、缩小、自适应显示、重置视图、添加曲线、移除曲线、数据提取、坐标轴设置、图例共 9 个带图标按钮
2. **Given** 右侧功能栏按钮对应功能已实现，**When** 用户点击该按钮，**Then** 功能正常触发，与菜单等价操作结果一致
3. **Given** 右侧功能栏按钮对应功能未实现，**When** 用户点击该按钮，**Then** 按钮呈禁用态或弹出"功能即将推出"提示，程序不崩溃

---

### User Story 4 - 应用图标统一呈现 (Priority: P2)

程序窗口标题栏、任务栏与任务切换器中均显示设计后的应用图标（雷达扫图形）。图标在 16px 到 256px 各尺寸下清晰可辨，深色主题下与界面协调。

**Why this priority**: 应用图标素材已由前序设计交付，本次只需验证集成完整；它属于"程序 icon 安装"要求的一部分，独立可测。

**Independent Test**: 启动程序，观察窗口标题栏与任务栏图标；在资源管理器中查看 exe 文件图标；截图记录。无需依赖功能按钮。

**Acceptance Scenarios**:

1. **Given** 程序已安装并启动，**When** 用户查看窗口标题栏、任务栏与 Alt+Tab 切换界面，**Then** 均显示设计版应用图标（而非默认空白图标）
2. **Given** 应用图标已配置，**When** 用户在 200% 缩放的任务栏上查看，**Then** 图标清晰可辨

---

### Edge Cases

- 图标资源缺失或路径错误时：按钮仍应可操作，回退显示文字或占位图形，程序不得崩溃，并在日志中记录错误
- 窗口宽度/高度过小时：左右功能栏应可隐藏（通过菜单或快捷键），不影响其他区域使用
- 用户将功能栏拖离停靠位置（浮动）后：图标与功能保持正常，恢复默认布局后功能栏回到原位
- 同一功能同时存在于菜单、左侧与右侧功能栏时：三处触发行为必须一致，不产生重复副作用
- 高 DPI（150%/200%）切换后：图标仍清晰，布局不错位
- 对尚不存在的功能（如撤销、重做、加载脚本、视频录制、刷新）：按钮点击不得造成崩溃或数据异常，需有明确状态（禁用/提示）

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在程序窗口、任务栏与任务切换器中显示设计版应用图标，替代默认图标
- **FR-002**: 系统 MUST 为所有菜单项配置与功能语义相符的图标；任一菜单项不得出现无图标状态（除非该项为分隔线等非操作项）
- **FR-003**: 系统 MUST 提供左侧纵向功能栏，包含且仅包含：撤销、重做、加载文件、加载脚本、主界面截图、主界面视频录制、刷新、数据面板显隐、属性面板显隐、命令窗口显隐 共 10 个按钮，每个按钮均带图标
- **FR-004**: 系统 MUST 保证左侧功能栏按钮与菜单对应操作行为一致（同一动作、同一结果）
- **FR-005**: 系统 MUST 提供右侧纵向功能栏，包含且仅包含：放大、缩小、自适应显示、重置视图（视图操作）与添加曲线、移除曲线、数据提取、坐标轴设置、图例（数据操作）共 9 个按钮，每个按钮均带图标
- **FR-006**: 系统 MUST 为每个功能栏按钮提供悬停提示（中文功能名），并为常用按钮提供键盘快捷键提示
- **FR-007**: 系统 MUST 支持图标五态呈现（正常、悬停、按下、禁用、选中），各状态视觉一致且可区分
- **FR-008**: 系统 MUST 在图标资源缺失时回退为文字/占位显示，程序不崩溃，并记录错误日志
- **FR-009**: 系统 MUST 支持菜单与功能栏的显隐控制，并在"恢复默认布局"时将功能栏复位到默认位置
- **FR-010**: 系统 MUST 确保图标在 100%/150%/200% 缩放下保持清晰（提供多分辨率图标资源）
- **FR-011**: 对暂未实现的功能按钮（撤销、重做、加载脚本、视频录制、刷新等），系统 MUST 呈现禁用态或明确提示，不得静默无响应或产生副作用

### Key Entities *(include if feature involves data)*

- **功能动作（Action）**: 菜单项与功能栏按钮共享的逻辑单元。每个动作包含功能名、图标、快捷键、可用状态。一个动作可在菜单和功能栏多处出现，行为一致
- **图标资源（Icon Asset）**: 以语义标识（如"打开文件""撤销"）索引的图标集合，供菜单与功能栏按语义复用

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户能仅凭图标正确识别 ≥ 90% 的功能按钮（抽样 10 项进行识别测试）
- **SC-002**: 程序启动到功能栏图标全部就绪的耗时 < 1 秒（正常硬件），启动过程无图标缺失的视觉闪烁
- **SC-003**: 左侧功能栏 10 个按钮与菜单对应动作 100% 对齐（点击结果一致，自动比对验证）
- **SC-004**: 全部菜单项与功能栏按钮均配置图标，运行时日志中图标缺失错误数为 0
- **SC-005**: 在 150% 与 200% 缩放下截图比对，图标无模糊、无拉伸、无错位（视觉抽查 5 处通过）
- **SC-006**: 新增图标（脚本加载、视频录制、刷新、面板显隐等，如需要）与既有图标集风格一致，通过既有图标规范校验工具检查无告警

## Assumptions

- 应用图标素材已由前序图标设计（002-icon-design）交付，本功能仅负责验证并确保其在窗口、任务栏等处的呈现，不重新设计应用图标
- 图标-功能映射遵循 002 交付的图标语义映射表；左侧功能栏的图标复用映射表中已有图标（撤销、重做、打开文件、导出截图等）
- 用户描述中"数据面板"指左侧数据/文件面板，"属性面板"指右侧属性面板，"命令窗口"指底部命令/控制台窗口；三者显隐均已有对应开关动作，本功能为其补充图标并放入左侧功能栏
- 右侧功能栏按钮集合已确认（用户选择：视图 + 数据混合）：视图操作（放大、缩小、自适应显示、重置视图）4 枚 + 数据操作（添加曲线、移除曲线、数据提取、坐标轴设置、图例）5 枚，共 9 枚；全部复用 002 图标映射表中已有图标（view-zoom-in、view-zoom-out、view-fit-screen、view-reset-camera、analysis-curve-add、analysis-curve-remove、analysis-extract、analysis-axis-settings、analysis-legend）
- 对撤销、重做、加载脚本、主界面视频录制、刷新等暂未实现的功能（用户确认）：本功能仅安装带图标的功能栏按钮，功能呈禁用态或占位提示，功能本体由后续独立规范实现
- 图标缺口（加载脚本、视频录制、刷新、面板显隐）按需新增图标，新增图标必须遵循图标设计规范（002）的风格、尺寸与校验要求，并登记到图标映射表
- 功能栏采用纵向布局；程序可随用户偏好调整功能栏显隐，恢复默认布局时复位
- 菜单项图标覆盖所有现有菜单（文件、编辑、视图、主题、日志、帮助等）；日志类菜单项（如打开日志目录、清除日志）若缺乏专用图标，使用语义最接近的既有图标
