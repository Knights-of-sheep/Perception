# 设计规范：Perception

> 设计入口文档。**规则层**唯一事实源为 `docs/design/ui-guidelines.md`（UI 设计系统），
> **视觉稿**唯一事实源为 `docs/design/mockups/`（本地 mockup）。
> 实现者须同时满足两者。

## 1. 设计基调

- 对标现代 IDE：深色主题、扁平化、高对比
- 无例外原则：所有组件主题统一（详见 ui-guidelines §4）

## 2. 布局（目标态）

```
+----------------------------------------------------+
| 菜单栏                                               |
| 工具栏 [打开] [导出] ...                              |
+-------------+----------------------+---------------+
| Dock:       | 中央曲线视图          | Dock:         |
| 文件树      |  (VTK Charts)        | 属性/曲线列表  |
|             |                      |               |
+-------------+----------------------+---------------+
| 状态栏                                               |
+----------------------------------------------------+
```

详细布局范式、专业细节、交互规范见 `ui-guidelines.md` §5 / §6。

## 3. 色板 / 字体 / 间距

见 `ui-guidelines.md` §3（分层色板 Token、Okabe-Ito 曲线色板、字体层级、几何一致性）。

## 4. 交互规范

- 平移：左键拖拽 / 缩放：滚轮（光标锚定）
- 右键：上下文菜单（导出图像、重置视图）
- 快捷键与易用清单：见 `ui-guidelines.md` §6
