# 设计规范：Perception

> 视觉设计规范。M2 里程碑产出 Figma 设计稿（或本地 mockup）后填充并成为唯一事实源。

## 1. 设计基调

- 对标现代 IDE：深色主题、扁平化、高对比

## 2. 布局（M2 细化）

```
+----------------------------------------------------+
| 菜单栏                                               |
| 工具栏 [打开] [导出] ...                              |
+-------------+----------------------+---------------+
| Dock:       | 中央曲线视图          | Dock:         |
| 文件树      |  (VTK Charts)        | 属性/曲线列表  |
|             |                      |               |
+-------------+----------------------+---------------+
| 状态栏                                               |
+----------------------------------------------------+
```

## 3. 色板（M2 填充）

- 背景 / 前景 / 强调色 / 曲线序列色板（针对色盲友好的 colormap）

## 4. 交互规范

- 平移：左键拖拽 / 缩放：滚轮（光标锚定）
- 右键：上下文菜单（导出图像、重置视图）

## 5. mockup 目录（免费方案，替代 Figma PAT）

设计稿（PNG + 说明）放 `docs/design/mockups/`，CodeBuddy 在 specify/plan/tasks
阶段读取作为设计上下文。
